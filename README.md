# TwitchMultiMiner

Мультиаккаунт-комбайн для одновременного фарма **Twitch Drops** на нескольких аккаунтах в **одном окне и одном процессе**, с десктопным интерфейсом на базе **Edge WebView2** (`pywebview`) и поддержкой системного трея Windows.

## Основные возможности

1. **Изолированные профили аккаунтов (`profiles/<account>/`)**:
   - Независимые `cookies.jar`, уникальный цифровой отпечаток клиента (`device_id`, `session_id`, `user_agent`) и индивидуальные прокси (`http://` / `socks5://`).
   - Общая матрица профилей в едином `asyncio` event loop без открытия отдельных окон для каждого аккаунта.
   - Встроенная панель OAuth-привязки (`twitch.tv/activate`) и импорт существующих профилей из соседнего `TwitchDropsMiner`.
2. **Графическая оболочка на Edge WebView2 (`ui/dashboard.html`) и трей Windows (`tray_win32.py`)**:
   - Живой статус всех воркеров, прогресс-бары, инспектор активного дропса, история полученных наград и общий журнал оркестратора.
   - Сворачивание в системный трей и тихий автозапуск без консольного окна.
3. **Кампании, превью наград и «Избранное»**:
   - Автоматическое кэширование изображений игр и предметов наград с интерактивной модалкой предпросмотра (`1x` / `2x`, переключение между наградами).
   - Фильтры по статусу (`Активные`, `В процессе`, `Предстоящие`, `Завершённые`, `Истекшие`), сортировка и звёздочка **Избранное** (`favorite_campaigns`), повышающая приоритет выбранных кампаний при добыче.
4. **Общий Радар кампаний (`radar.py`) и 3 пресета в 1 клик**:
   - Прямой опрос `GetStreamInfo` + `AvailableDrops` + `CampaignDetails` через Twitch GQL, общий кэш публичного каталога и режим дежурства на онлайн-стримерах (`Standby Mode`).
   - **Базовый (Топ и GTA 6)** — фокус на топ-стримерах, приоритетных играх и авто-ключах.
   - **Все доступные кампании** — автоматический приоритет всех незавершённых кампаний с дропсами (из инвентаря и каталога).
   - **Игры на ПК** — автоматическое определение установленных на ПК игр (**Steam**, **Epic Games Launcher**, **Riot Games**, **GOG**, **Ubisoft Connect**, реестр Windows) с переключением в режим `PRIORITY_ONLY`.
5. **Устойчивый механизм просмотра и авто-клейма**:
   - Динамический `client_time` в payload, гибридный HLS + Spade (`minute-watched`) пульс с общим кэшем `spade_url`.
   - Активная синхронизация прогресса по GQL `CurrentDrop` каждые ~55 секунд и гарантированный авто-клейм (`generate_claim`).
   - Встроенный UDP DNS-резолвер (`1.1.1.1` / `8.8.8.8`) на случай проблем системного DNS.

## Установка

Требуется Python 3.10+ (для GUI на Windows рекомендуется Edge WebView2 Runtime, встроенный в Windows 10/11).

```bash
pip install -r requirements.txt
```

## Запуск

- **Графический интерфейс (обычный старт):**
  ```bat
  start_gui.bat
  ```
- **Тихий запуск в системный трей с автостартом профилей:**
  ```bat
  start.bat
  ```
- **Через Python / CLI:**
  ```bash
  python main.py                  # GUI-дашборд
  python main.py --tray --autostart
  python main.py --headless --autostart
  python main.py --import-legacy
  ```
